Unslop Results on Slop Code Bench

Use two strategies on six problems: tweak the spec if ambiguous, and use a new prompt, "spectest". Two more arms: anti-slop, the benchmark's own quality prompt, and spectest+antislop, which adds that prompt's rules to spectest. Every figure is lower-is-better. Two runs per problem, using Claude Opus 5.

The spectest prompt replaces the benchmark's default, just-solve. Spectest guides the agent to write tests from the spec before implementing. The agent splits the spec into phrases, writes a test for each one, and logs every ambiguity. This spectest is my 12th version. In the code, it's called min12-ABDJKMN. Version 12 was split into chunks A to S, and then trimmed. The remaining bits are: A and B are shell tool hygiene, D writes tests from the spec, J and K log ambiguities, M and N speed up execution by running focused tests. anti-slop is the benchmark's upstream anti_slop prompt as shipped, the paper's Anti-Slop arm, so the paper's faint Anti-Slop lines below are its counterpart. spectest+antislop (min13-ABDJKMNT) is spectest with one chunk appended, T: that prompt's rule list, unchanged. anti-slop against just-solve is the paper's own comparison; spectest+antislop against anti-slop is what writing tests first adds on top of the rules.
