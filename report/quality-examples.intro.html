What just-solve wrote, and what spectest wrote instead

Code Opus 5 wrote for the six dev problems under the benchmark's just-solve prompt, at the final checkpoint, spec v0. Tinted lines are what scb-check 0.1.3 flagged. The switch on each example shows what the spectest prompt (min12-ABDJKMN) wrote for the same job in its own run. Implementation files only, because spectest's test files dilute its scores.

These are not representative. They were picked by hand from 21 candidates to show spectest at its best. On other code from the same runs its version is no better: the same isinstance ladder line for line, a CC 25 main that stays CC 25, a check pasted three times on both sides.
