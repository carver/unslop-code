datagate v2

An HTTP service that ingests remote CSV files and serves them back as JSON. Seven checkpoints.

01

Encoding fallback, rowid origin, upload charset, spreadsheet charset, force value

entered v1 · 2026-09-02 · checkpoints 1, 2, 4, 5 · 01-datagate-clarified.patch

checkpoint 1
−| `charset` | no | Character encoding for decoding CSV bytes. If omitted, detect encoding from content. |
+| `charset` | no | Character encoding for decoding CSV bytes. If omitted, detect unambiguous encoding from content, else latin-1. |
checkpoint 2
−`_shape=objects`: `rows` is objects and includes `rowid` (1-based source-file row number). `rowid` is not in `columns`.
+`_shape=objects`: `rows` is objects and includes `rowid` (1-based source-file row number, starting at the header). `rowid` is not in `columns`.
checkpoint 4
−`POST /upload` accepts multipart form with field `file` or `attachment`.
+`POST /upload` accepts multipart form with field `file` or `attachment`, and `charset` query parameter.
checkpoint 4
−`charset` applies only to text CSV sources.
+`charset` applies and validates only for text CSV sources.
checkpoint 5
−Any additional `force` value is `HTTP 400`.
+Any `force` value is `HTTP 400`.

entered v2 · 2026-09-05 · checkpoint 7 · 02-datagate-enrich-single.patch

−Only exact `enrich=yes` enables enrichment.
+Only a single, exact `enrich=yes` enables enrichment.

Delimiter inference only when a delimiter is present

entered v2 · 2026-09-05 · checkpoint 1 · 03-datagate-delimiter-if-present.patch

+- Delimiter must be inferred from input, if present; minimum supported delimiters are `,`, `;`, and `\t`.

entered v1 · 2026-09-09 · checkpoint 2 · 01-tsv-crlf.patch
